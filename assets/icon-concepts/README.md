# Propuestas de icono — Emulos360

Generadas con la herramienta integrada imagegen. El usuario eligió la opción 2,
Orbit 360. Aplicada como icono de Emulos360 en la interfaz y en los ejecutables.
Original conservado en `02-orbit-360.png`; recursos de aplicación en
`../emulos360.png` y `../emulos360.ico`. El ICO contiene tamaños de 16 a 256 píxeles
y se regenera con `scripts/build-icon.ps1` desde la raíz del proyecto.

### Opción 1

Use case: logo-brand. Create ONE finished app icon concept for Emulos360, a modern native Xbox 360 emulator for Windows and Linux. Square 1024x1024 composition. Icon itself fills about 82% of the canvas with ample symmetric padding. Transparent background outside the icon. Extremely crisp professional identity design, distinctive strong silhouette readable at 32px, no mockup, no desktop scene, no caption, no watermark, no tiny details. Do not reproduce Xbox's X-sphere mark or any existing brand logo. No full application name or other text. Palette coordinated with the app: charcoal #101211, electric lime #c1f777, warm off-white #f3f5ef. Concept 1 — PULSE E: a bold custom geometric capital E monogram, built from three decisive forward-cut lime strokes fused into one compact symbol. The middle arm has a subtle forward-play cut made of negative space, not a separate triangle. Set on a refined charcoal rounded square tile with a very restrained rim and subtle depth. Mostly flat precision with slight dimensional polish, timeless desktop software branding, striking bold simplicity.

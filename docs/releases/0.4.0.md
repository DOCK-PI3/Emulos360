# Emulos360 0.4.0

Añade Canary Edge como segundo core opcional, seleccionable desde **Ajustes →
Cores** o por título desde **Biblioteca → Motor**. Permite escoger Direct3D 12 o
Vulkan en Windows y Vulkan en Linux. El core actual permanece seleccionado por
defecto y conserva su binario e integración Netplay/MultiP.

Edge es experimental y abre su propia ventana. Mantiene ajustes, cachés, partidas
y logros independientes; copia inicialmente el perfil y contenido del título sin
sobrescribir archivos existentes. Sus avances posteriores no se sincronizan con
el core actual. Las funciones de perfiles, Logros, Partidas, avatares, dashboard y
Netplay de Emulos360 siguen utilizando el core actual.

Los paquetes incluyen la revisión oficial fijada 0788c56 y su licencia. Windows
incluye los runtimes de Direct3D requeridos por esa revisión. La actualización desde
0.3.0 conserva la carpeta de datos.

Validación: aplicación compilada para Windows y Linux; pruebas de preferencias,
servicios, biblioteca, interfaz, voz, lanzamiento y aislamiento; ASan/UBSan del
componente de opciones y copia; simulación del instalador 0.3.0 en ambas plataformas.
Se ha comprobado la carga del ejecutable de NEW RALLY-X en Edge; no se han validado
partidas completas ni nueva compatibilidad online.

Guía: [uso y límites de los dos cores](../DUAL_CORE.md).

Para publicar, crea una release estable con etiqueta **v0.4.0**, copia estas notas
(excepto este párrafo) y adjunta los dos paquetes y sus `.sha256` de
`out/release-v0.4.0`. La API de GitHub debe exponer el digest SHA256 de cada paquete
para que el actualizador de 0.3.0 permita instalarlo. Consulta [UPDATES.md](../UPDATES.md).
